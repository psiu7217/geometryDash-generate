# Geometry Dash AI Level Generator

Генератор уровней Geometry Dash по текстовому промпту: строит объекты, сохраняет
`.gdlvl`, рисует PNG-предпросмотр и импортирует уровень в игру безопасным способом.

> Статус разработки — в [PROGRESS.md](PROGRESS.md). Технические решения и
> исследование окружения — в [docs/RESEARCH.md](docs/RESEARCH.md) и
> [docs/FORMAT.md](docs/FORMAT.md).

## Что уже умеет

- Генерация уровня из описания на русском или английском (`generate`).
- Правка уже сгенерированного уровня промптом (`edit`): сложность, длина,
  декорации, замена игрового режима, ускорение второй половины.
- Экспорт `.gdlvl` — родной формат импорта Geometry Dash 2.209+.
- PNG-предпросмотр всей трассы с маршрутом игрока.
- Безопасный offline-импорт в `CCLocalLevels.dat` (резервная копия, проверка,
  что игра закрыта) — опционально.
- Автотесты структуры уровня, round-trip формата и физических ограничений.

## Требования

- Windows + Steam-версия Geometry Dash **2.209 / 2.2091** (нативный импорт `.gdlvl`).
- Python 3.10+ (используется только стандартная библиотека, зависимостей нет).

## Быстрый старт

```powershell
# Сгенерировать AI Neon Run (первый тестовый уровень)
py -m gdgen generate --preset ai-neon-run --out levels

# Произвольный промпт
py -m gdgen generate --prompt "Создай уровень в стиле космоса на 60 секунд" --out levels

# Только предпросмотр из существующего .gdlvl
py -m gdgen preview levels/ai_neon_run.gdlvl

# Правка уровня промптом
py -m gdgen edit levels/ai_neon_run.gdlvl --prompt "Добавь больше декораций и замени Ship на Wave"

# Импорт в игру (игра должна быть закрыта!)
py -m gdgen import levels/ai_neon_run.gdlvl
```

## Импорт в Geometry Dash

**Рекомендуемый способ (безопасный, штатный):**

1. Закройте игру перед изменением сохранений (для offline-импорта).
2. Откройте `levels/ai_neon_run.gdlvl` в игре: экран создания уровня →
   кнопка **Import** (Geometry Dash 2.209+).
3. Уровень появится в списке локальных уровней и откроется в редакторе.

**Альтернатива:** `py -m gdgen import FILE.gdlvl` добавляет уровень прямо в
`CCLocalLevels.dat`. Скрипт:

- отказывается работать, если `GeometryDash.exe` запущен;
- делает резервную копию `CCLocalLevels.dat` рядом с оригиналом;
- пишет во временный файл, проверяет обратное чтение и только потом заменяет
  сохранение;
- никогда не удаляет существующие уровни.

Steam Cloud: после импорта при закрытой игре Steam может синхронизировать
сохранение. Если облако перезапишет файл, отключите синхронизацию для игры или
импортируйте через нативный Import.

## Ограничения

- Уровень **не проверен реальным прохождением**. Автоматически проверяются
  только структура, формат и грубые ограничения физики.
- Генератор не публикует уровни в сеть и не изменяет онлайн-статистику.
- `.gdlvl` не является официально документированным форматом; реализация
  основана на наблюдаемом формате GD 2.209 (см. `docs/FORMAT.md`).

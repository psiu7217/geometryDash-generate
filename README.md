# Geometry Dash — генератор уровней по промпту

Python CLI для Geometry Dash 2.209+. Генерирует редактируемые локальные уровни
`.gdlvl`, строит **статический** PNG-предпросмотр по тем же объектам, позволяет
изменять параметры текстом и безопасно импортировать уровни в локальное сохранение.

Исходный MVP **AI Neon Run** был вручную импортирован в игру и пройден пользователем
6 ноября 2026 года. **Neon Cyber City** тоже проверен в игре: запускается, однако
пользователь отметил **слишком высокую сложность**. Проходимость любых других
seed/пресетов по-прежнему требует проверки в игре.

## Moonlit Cloud Kingdom (новый игровой пресет)

На основе присланного визуального референса (сиреневое ночное небо,
луна, парящие облака, звёзды и арки) добавлен новый пресет.
Имя файла: `levels/moonlit_cloud_kingdom.gdlvl`; название в GD:
**Moonlit Cloud Realm** (лимит 20 символов).

- ~60 секунд, Easy, Cube → Ship → Ball → Wave.
- Перекрывающиеся входные порталы по высоте для безопасных переходов
  Ship → Ball (4 портала) и Ball → Wave (3 портала); восстановление
  гравитации перед Wave.
- **2 795 объектов** (в текущей сборке), **8 одиночных шипов**, 2
  необязательных жёлтых orb; около 60 секунд.
- **Ship теперь требует управления высотой:** вместо прямого коридора —
  плавный S-образный маршрут между широкими верхними и нижними стенками;
  прямой полёт на фиксированной высоте упирается в препятствия.
  Проход >=180 units в расчётной геометрии; это не подтверждённый playtest.
- Больше декора: парящие дворцы, кристаллы, арки, дополнительные
  звёзды, подсказки направления и многослойные облака. Декоративные
  объекты вынесены в реальный фоновый Z Layer B4.
- Нативные декоративные облака, круглый диск луны, аркады, светящиеся
  звёзды и фоновые эффекты; статические и декоративные триггеры.
- Создаются основной и детальный PNG, а CI дополнительно создаёт
  `_cube.png`, `_ship.png`, `_ball.png`, `_wave.png`.
- Проверена структурная корректность и round-trip .gdlvl; **игровой
  playtest конкретно этого нового уровня ещё не выполнен**. PNG
  схематичный, а не пиксельное совпадение с референсом.
- У нового пресета есть собственный облегчённый шаблон Ball и широкий
  Wave-коридор с мягким зигзагом: высота 280 units, плавное смещение
  48 units за ~4.2 с, плоская входная полка. Платформы бело-лиловые с
  тонкой светящейся нетвёрдой кромкой.
- Статический валидатор проверяет целевые Group ID и Color ID
  триггеров, встраивание портала в блок, окно реакции после портала
  и дублирующиеся порталы. Это по-прежнему не симуляция физики.

```powershell
py -m gdgen generate --preset moonlit-cloud-kingdom --out levels
py -m gdgen inspect levels/moonlit_cloud_kingdom.gdlvl
```

## Быстрый старт

Требуется Python 3.10+; внешних Python-зависимостей нет.

```powershell
# 60 секунд Hard, Cube → Ship → Wave → Cube, городские декорации
py -m gdgen generate --preset neon-cyber-city --out levels

# Сначала только картинки. Файлы .gdlvl/.json не создаются
py -m gdgen generate --preset neon-cyber-city --out draft --preview-only

# Конкретный промпт с BPM (BPM управляет только декоративным ритмом)
py -m gdgen generate --prompt "Киберпанк, 60 секунд, сложный, много декораций, 140 BPM" --out levels

# Увеличить фрагмент: 90 блоков с отметки 100
py -m gdgen preview levels/neon_cyber_city.gdlvl --start-block 100 --blocks 90 --width-per-block 14 --height-per-block 18

# Изменить спецификацию и сохранить новую копию, не удаляя старый JSON
py -m gdgen edit levels/neon_cyber_city.gdlvl --prompt "Добавь больше декораций" --out levels/neon_cyber_city_v2.gdlvl

# Проверка структуры
py -m gdgen inspect levels/neon_cyber_city.gdlvl

# Опциональный offline-импорт при ЗАКРЫТОЙ игре
py -m gdgen import levels/neon_cyber_city.gdlvl
```

## Что нового во втором этапе

- Пресет **Neon Cyber City**: 60 секунд, Hard, палитра cyber,
  секции Cube / Ship / Wave / Cube.
- Дополнительные декоративные объекты (#1904, #1887): здания, подсветка,
  верхние контуры и световые акценты. Декор отделён от игровых блоков.
- Параметр `bpm` в `LevelSpec`, распознавание `120 BPM` / `BPM: 120`;
  декоративные маркеры учитывают скорости секций.
- Два предпросмотра: общий `preview/NAME.png` и увеличенный фрагмент
  `preview/NAME_detail.png`; увеличенный участок можно выбрать вручную.
- `--preview-only`: рассмотрение результата до сохранения импортируемого файла.
- Исправлено чтение вложенного тега `<d>` из `CCLocalLevels.dat`,
  сохранён исходный JSON при `edit --out`.

## Импорт в игру

Самый безопасный вариант — штатная кнопка **Import** в Geometry Dash 2.209+.
Получившийся уровень редактируется обычным редактором игры.

При прямой модификации `CCLocalLevels.dat` генератор откажется работать,
если Geometry Dash запущена, предварительно сделает резервную копию и не
должен удалять другие уровни. Steam Cloud может повлиять на сохранения;
штатный импорт предпочтительнее.

## Автоматическая проверка

```powershell
py -m unittest discover -s tests -v
```

Workflow `.github/workflows/generator.yml` проверяет код на GitHub Actions,
генерирует файлы примера и, при наличии разрешений Actions, фиксирует
детерминированные примеры в `main`. Результат сборки также доступен как
artifact **neon-cyber-city** в разделе Actions.

## Честные ограничения

- Обработка промптов сейчас **правиловая**, это не универсальный LLM:
  неизвестные формулировки не обязательно будут поняты.
- PNG — **приблизительный рендер**, а не скриншот игрового движка. Градиенты,
  свечения, наложения и эффект триггеров могут отличаться.
- Декоративные ID взяты из публичных списков Geometry Dash 2.2;
  новый пресет проверен в игре, но **показался пользователю слишком сложным**.
  Отдельные свойства и виды декора могут требовать дополнительной проверки.
- BPM акцентов не означает реальной синхронизации с музыкальным треком:
  его BPM и смещение должны быть подобраны отдельно.
- Маршрут и проходимость проверяются эвристически. Прохождение AI Neon Run
  пользователем не доказывает проходимость любого нового уровня.

# Формат уровня Geometry Dash (2.2 / 2.209)

Документ описывает только те части формата, которые использует генератор.
Источники: наблюдаемый формат GD 2.209, открытые парсеры
[GDParse](https://github.com/HectLM/GDParse) и
[gdparse](https://github.com/kuzheren/gdparse), измерения GD AI Bridge.

## 1. Контейнер `.gdlvl`

```
bytes = urlsafe_base64( gzip( utf8(XML plist) ) )
```

XML:

```xml
<?xml version="1.0"?>
<plist version="1.0" gjver="2.0">
  <dict>
    <k>kCEK</k><i>4</i>
    <k>k2</k><s>AI Neon Run</s>
    <k>k4</k><s>H4sI....</s>   <!-- строка уровня, gzip + base64url -->
    ...
  </dict>
</plist>
```

`k4` может быть как сжатой, так и простой строкой; GD 2.209 экспортирует
сжатую. Генератор всегда пишет сжатую.

## 2. Строка уровня

```
<header>;<object>;<object>;...;
```

### Заголовок

Пары `key,value`, разделённые запятыми. Используемые ключи:

| Ключ | Значение |
|---|---|
| `kS38` | цветовые каналы, `|`-разделённые, значение заканчивается `|` |
| `kA6` | id канала фона (обычно `1000`) |
| `kA7` | id канала земли (обычно `1001`) |
| `kA4` | стартовая скорость (0 = normal) |
| `kA2` | стартовый режим (0 = cube) |
| `kA13` | смещение музыки |
| `kA15`, `kA16` | fade in/out музыки |
| `kA17` | линия пола |
| `kA18` | шрифт |
| `kS39` | 3D-линия |

Канал в `kS38`:

```
1_<r>_2_<g>_3_<b>_4_-1_6_<channel>_7_<alpha>_15_<blend>_18_0_8_1
```

- `r,g,b` — 0..255
- `6` — id канала (1..999, 1000 bg, 1001 ground, 1002 line, 1003 3D line,
  1004 obj, 1005 player 1, 1006 player 2, 1007 light bg, 1009 ground 2)
- `7` — alpha 0..1
- `5` — blending (1 = additive/glow)
- `15` — blending flag в современных сохранениях

Несколько каналов разделяются `|`, после последнего тоже стоит `|`.

### Объект

```
1,<id>,2,<x>,3,<y>[,<prop>,<value>...];
```

Координаты — в units, 1 блок = 30. Центр клетки: `15 + 30*k`.
`y=15` — первый ряд над землёй (центр блока, лежащего на земле).

Используемые свойства:

| Prop | Смысл |
|---|---|
| `1` | object id |
| `2`, `3` | x, y |
| `4`, `5` | flip X / flip Y |
| `6` | rotation (градусы) |
| `20` | editor layer |
| `21` | основной цветовой канал |
| `22` | дополнительный цветовой канал |
| `32` | uniform scale |
| `128`, `129` | scale X / scale Y |
| `35` | opacity (у ряда триггеров) |
| `57` | groups, через точку |
| `7`, `8`, `9` | RGB (color trigger) |
| `10` | duration (trigger) |
| `23` | target color channel (color trigger) |

## 4. Физика (измерения GD AI Bridge)

1x (normal):

- высота прыжка куба ≈ 64 units;
- длина прыжка: slow 106, normal 136, fast 176, faster 206, fastest 252;
- жёлтый pad: высота 131, длина 189;
- розовый pad: высота 55, длина 124;
- жёлтый orb: как обычный прыжок (64 / 130);
- розовый orb: высота 33, длина 91.

Ship (normal, удержание с земли): +2 units через 15, +24 через 60, +90 через
120, +131 через 150; после отпускания подъём продолжается ≈70 units на ≈120
units пути.

Генератор использует консервативные допущения: одиночный шип перепрыгивается
одним прыжком, двойной — тоже (ширина 60 < 136), коридор ship — не уже 4 блоков
(120 units) на normal и 5 блоков на fast.

## 5. Кодирование сохранения `CCLocalLevels.dat`

```
XOR 11 → url-safe base64 → gzip → XML plist
```

Структура: `<plist><dict><k>LLM_01</k><dict><k>k_0</k><dict>…уровень…</dict>…`.
Новый уровень вставляется как `k_0`, остальные сдвигаются на `k_1`, `k_2`, …
Ключи уровня, важные для импорта: `kCEK`, `k2`, `k4`, `k13`, `k16`, `k21`,
`k45`, `k50`, `k80`, `k101`, `k156`, `kI1`–`kI6`.

## 6. Ограничения реализации

- Формат неофициальный; поведение может измениться в следующих версиях игры.
- Генератор не претендует на полную поддержку всех свойств GD 2.2.
- Проверка проходимости — эвристическая; реальное прохождение не выполняется.
